# Product Dashboard

This project is a simple Product Dashboard built using **HTML, CSS, and JavaScript**. Mục tiêu của dự án là tạo giao diện quản lý sản phẩm cơ bản với bố cục rõ ràng, dễ tùy chỉnh và có thể chạy trực tiếp trên trình duyệt mà không cần cài đặt thêm.

Dashboard bao gồm các thành phần như header, sidebar điều hướng, danh sách sản phẩm, các thẻ hiển thị thông tin và một số hiệu ứng tương tác bằng JavaScript. Toàn bộ mã nguồn được viết thủ công, không sử dụng framework, giúp dự án nhẹ, dễ hiểu và phù hợp cho người mới học.

Bạn có thể clone repo này, sau đó mở file **index.html** để chạy ngay lập tức. Dự án rất dễ mở rộng nếu muốn bổ sung chức năng quản lý sản phẩm, thêm API hoặc chuyển sang phiên bản dùng backend.
